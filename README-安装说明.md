# QDC507 模块网页安装包 0.3.43

这是安装到 **4G 模块内部** 的程序。电脑只负责通过 USB 传输，安装后程序存放在模块 `/usrdata/qdc-web/`。本包不包含 Mac 通信助手或 OpenWrt 网关。

## 适用模块

适用于与原开发模块相同的 QDC507、ARMv7、Linux 3.18.44 原厂系统，要求开放 root ADB，保留厂家的 QMI、音频库、httpd、curl 等依赖。不同固件、其他型号或内核不匹配的模块不适用。安装脚本检查已知依赖；通过预检仍需确认硬件型号，不能只根据 ARM 架构判断兼容。

这是**全新模块首次安装包**。已存在 `/usrdata/qdc-web/` 的模块会拒绝覆盖，不作为升级包使用。

## 包里有什么

| 文件 | 用途 |
| --- | --- |
| `install.py` | 在电脑上运行的 USB 安装入口 |
| `module-install.sh` | 安装入口调用的模块端脚本 |
| `payload/www/` | 网页及已编译的通讯、音频、eSIM 程序 |
| `payload/standalone/` | 网页转发入口、独立运行服务、花生壳客户端及语音驱动 |
| `payload/lib/` | eSIM 的可替换共享库 |
| `payload/usb-compat/` | USB 漫游兼容驱动，首次安装默认关闭 |
| `payload/licenses/`、`THIRD-PARTY.md` | 第三方许可及来源 |
| `third-party-source/` | libeuicc 等第三方组件的对应源码与重建说明；不安装到模块 |
| `SHA256SUMS`、`release.json` | 文件校验和发布信息 |

不含原模块的管理员密码、花生壳设备身份、Bark 地址、短信、通话记录、流量记录、旧版备份或采集工具。网页 HTML/JS/CSS 本身可查看；核心后台以 ARM 程序分发，不含本项目 C 源码。

## 1. 准备

1. 电脑安装 Python 3.9 或更新版本，以及 Android platform-tools 中的 ADB。
2. 解压安装包，进入解压后的目录。
3. 将一个符合上面要求的全新模块插入电脑 USB，退出正在占用模块的通信助手。多设备时，给下面的命令加 `--serial 模块编号`。

Mac、Linux 使用 `python3`；Windows 可改用 `py -3`。ADB 不在系统路径时，加 `--adb` 和 ADB 文件完整路径。

## 2. 只读预检

```sh
python3 install.py check
```

这一步只读模块状态，不上传文件、不修改模块。检查系统版本、依赖、USB 地址、可用空间及端口占用。

## 3. 首次安装

```sh
python3 install.py install --apply
```

有自己的 HTTPS 公网域名时，可在首次安装时直接指定：

```sh
python3 install.py install --apply --origin https://你的域名
```

安装会写入约 3 MiB 程序，生成新管理员密码，启动本地网页、网页转发入口和短信/电话事件监听。首次安装暂不开启花生壳、音频初始化和开机启动，不修改 APN、SIM PIN 或号码配置。

成功后，在包目录生成权限受限的 `initial-password-xxxxxxxx.txt`，里面是新模块的登录密码。密码不会打印到终端；成功保存到电脑后，模块上的临时明文密码会删除。Windows 目录权限由系统账户控制，请保管该文件，不要再把它一起分发。

打开 **http://192.168.225.1/**，用户名 `admin`，用新密码登录。在设置里确认版本为 0.3.43，并修改登录密码。

如果安装中途 USB 断开、密码尚未保存，重新连接后执行：

```sh
python3 install.py save-password --apply
```

它只取回首次安装密码，不重设密码。若该文件已删除，请使用自己保存或修改后的密码。

## 4. 启动完整服务与开机启动

确认模块型号和内核相同、当前没有通话后，启动完整服务：

```sh
python3 install.py start --apply
```

这一步按本项目已有服务逻辑加载随包的语音驱动、准备声卡、协调蜂窝联网/USB 设置并启动音频服务。不会主动拨号或发短信；网页仍需 HTTPS 才能获取手机麦克风。若音频初始化失败，服务可能保留网页并输出提示，应先排查，不要把“启动已执行”理解为通话已验证。

让模块断电重新上电后自动启动：

```sh
python3 install.py enable-startup --apply
```

此操作增加本项目的系统开机入口 `/etc/init.d/qdc-web-standalone` 和 `/etc/rc5.d/S99qdc-web-standalone`，短暂将系统分区改为可写并恢复原只读状态。不会刷固件。应在本地网页与服务验证后再执行。

## 5. 花生壳首次注册与公网映射

全新模块需注册自己的设备身份，不能使用他人模块的设备配置。保持模块能够联网，执行一次：

```sh
python3 install.py init-oray --apply
```

客户端向花生壳服务器申请新设备，最多等待约 60 秒，保存有效身份后开启服务。已存在身份时脚本拒绝重新注册。注册失败时会停止本次客户端；若提示存在运行文件，应先核对原因，不要删除文件反复申请新身份。

随后在模块网页 **应用 → 花生壳** 获取二维码，使用自己的花生壳 App 扫码绑定。公网映射按下面填写：

| 项目 | 值 |
| --- | --- |
| 设备 | 新模块对应的花生壳设备 |
| 类型 | HTTPS |
| 内网主机 | `127.0.0.1` |
| 内网端口 | `8788` |

域名确定后，执行：

```sh
python3 install.py set-domain --apply --origin https://你的域名
```

这会在电话空闲时重新启动本项目服务，使音频与转发入口采用自己的公网域名，不会修改花生壳服务器上的映射。未指定域名时使用 `https://example.invalid` 占位，不能据此公网访问。

从自己的 HTTPS 域名打开网页，登录后测试双向通话。仅通过本地 HTTP 页面不能调用手机麦克风。

## 安装中断如何处理

- 首次安装在提交前失败：只删除本次候选目录，已有模块项目不覆盖。
- 提交后或服务启动失败：保留已写入的项目及新密码，方便取回密码、检查日志；不会删除数据，也不自动重试拨号、短信或注册。
- 驱动初始化或花生壳注册出现问题时，先保留 USB 本地入口，检查模块服务状态。
- 包内没有一键删除模块数据的脚本。首次部署已提交后，重新运行首次安装会拒绝覆盖。
