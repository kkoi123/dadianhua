# QDC507 模块网页后台

当前模块网页版本：**0.3.43**。

程序直接运行在 QDC507 4G 模块内部，网页访问、短信、电话和应用设置由模块本地后台提供。电脑用于开发或通过 USB 安装，安装后不需要电脑常驻运行。

## 功能

- 网络：运营商、信号、SIM 状态、蜂窝联网、USB 上网、数据漫游和 USB 漫游兼容设置。
- 短信：读取、发送、回复、删除，显示卡片存储标记及发送记录。
- 电话：拨号、接听、挂断、网页双向音频、模块后台通话记录。
- 应用：花生壳设备绑定与心跳设置、Bark 提醒、兼容卡片的 eSIM 配置管理。
- 系统：模块资源状态、断电恢复的流量统计、管理员密码及会话管理。

本地管理地址为 `http://192.168.225.1/`。网页通话的麦克风访问需要自己的 HTTPS 公网入口。eSIM 功能要求卡片本身支持 eUICC，普通 SIM 不会因安装本项目变成 eSIM。

## 源码目录

```text
module-web/
  *.c, *.h, *.inc       模块后台、QMI、音频、统计和配置恢复
  static/              网页 HTML、CSS、JavaScript
  test_*               本地模拟测试
  vendor/              固定版本的第三方源代码及来源校验
  usb-compat/          USB 转发兼容组件源码与内核构建配置
  packaging/           首次安装入口、发布打包及许可证
  scripts/             本地检查与源码打包工具
```

模块实现和构建步骤见 [module-web/README.md](module-web/README.md)。

## 上传前检查

```sh
python3 module-web/scripts/check-source.py
python3 module-web/scripts/package-source.py --output ../qdc507-source-export
```

源码包会排除构建产物、工具缓存、安装包、历史部署记录、凭据、日志及编辑器数据。生成的源码 ZIP 与模块安装 ZIP 用途不同：源码用于阅读、修改和编译，不能直接作为安装包写入模块。

请在 GitHub 仓库文件区上传本目录的清理后源码；安装包放在 Releases。不要把安装后生成的密码文件或模块 `private` 目录重新添加进来。

## 依赖与验证边界

目标为同型号 QDC507、ARMv7 EABI5 soft-float、Linux 3.18.44 原厂系统。QMI、原厂音频库和系统工具由模块固件提供，本目录不包含这些厂家库。

语音 `.ko` 驱动属于外部预编译依赖，完整安装包构建需单独提供匹配组件；本项目的 USB 兼容组件提供 C 源码和构建说明。源代码整理没有连接、写入或重启硬件。已发布安装包的首次部署仍需在目标同型号模块上验证。

第三方代码按各目录中的原许可执行。当前没有为自研部分新增统一开源许可证，上传源码本身不等于授予任意再分发或商用许可。
